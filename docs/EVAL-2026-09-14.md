## 本次演练暴露的技能设计缺口（待补进 `01_`）

1. **"标称值 = 别名口径"要校验**：deepseek 官方文档明确 `deepseek-flash` 是现行名、`deepseek-v4-flash` 已退役 → 技能需比对"配置里的 model id"与"官网列出的 model id"，不一致时提示。
2. **cap 不得低于 reserve 的护栏必须前置**（本次 M2.x 就是活例）：应在决策卡阶段就标 ✗，而不是等执行段拒绝。
3. **未使用模型的默认处理**：建议默认不配（只配在用 + 旁路在用），避免为"备胎"引入冲突。
4. **附带发现要单独收口**：如 `maxTokens 8192 vs 官方 384K`，应作为"顺带发现"清单输出，不混进本次 patch。
