# xiaoyaoclaw-context-budget · 上下文检查

> **一句话**：把「模型上下文窗口该配多大」这件事，变成一次检查 + 一次确认。
> 技能会检测你系统里**已启用**的模型，去模型官网取最新标称窗口，按 **60%** 给出建议值，你确认后才写入配置。

> 草稿状态：本文件为技能 README 草稿（技能尚未打包）。定稿后作为技能根目录 `README.md` 发布。

---

## 为什么需要它

各家模型的上下文窗口差别很大（有 200K、1M…），而 OpenClaw 在模型未声明时会退回一个**兜底默认值**，容易造成：

- 窗口被低估 → 上下文被**过早自动摘要**，长任务被打断
- 窗口被高估或随便填 → 模型注意力分散，回答质量下降

本技能按一条固定最佳实践处理：**有效窗口 = 厂商标称窗口 × 60%**（留出余量，减少注意力分散）。

## 使用流程：检测 → 决策 → 执行

**① 检测（自动，你不需要提供任何信息）**

技能自己做四件事：找系统里在用的模型 → 去各模型**官网**取最新标称窗口 → 与当前配置比对 → 按 60% 算建议值。

- 无差异 → 一句话结束：`✅ 检测完成：模型窗口都合适，无需调整。`
- 有差异 → 出决策卡（见下）

**② 决策（你只回一个数字）**

```
🎛️ 检测到 1 项可调整
· minimax/MiniMax-M3（图像）｜ 官网标称 1,000,000 ｜ 现值 200,000 → 建议 600,000
· deepseek-flash（在用）｜ 官网 1,000,000 ｜ 现值 600,000 ✅ 无需调整
*建议值 = 官网窗口 × 60%（留余量，防注意力分散）*｜来源：官方文档（抓取时间已在卡上标明）

回 1 采纳 ｜ 2 保持现状 ｜ 3 看详情
```

**③ 执行（自动，回执 3 行）**

```
✅ 已改 1 项：minimax/M3 200,000 → 600,000
校验通过（窗口已生效）
如需撤销回「撤销」（已自动备份）
```

备份、写入、刷新、清理、校验、留痕全部在幕后完成。

## 行为边界（技能只做这一件事）

| 做 | 不做 |
|---|---|
| 设置**已启用模型**的上下文窗口（按 60%） | `maxTokens`（输出上限）等其它参数 |
| 读取配置、取官网标称、写入窗口值 | 压缩阈值（保持系统默认，不碰） |
| 改动前可回退（支持一条指令撤销） | 未在用模型的默认批量配置 |
| 取不到官网标称时向你确认 | 静默执行（必须经你确认才写配置） |
| — | **不记录修改历史、不留审计痕迹**（用完即走） |

## 可选建议配置（按需自选，技能不强制）

以下两项**不是技能默认行为**，如果你希望更省心，可以自行启用：

### 1. 定期自检（推荐：每周一次）

让技能定期自动跑一次「检测 + 比对」，**没有变化时完全静默**，只有厂商真的改了窗口才提醒你。

| 频率 | 适合 |
|---|---|
| 每周一 09:00（建议） | 常规使用 |
| 每两周 | 模型库变动少 |
| 不自动 | 只在需要时手动说「上下文检查」 |

配置方式（OpenClaw cron，isolated 任务）：

```jsonc
{
  "schedule": { "kind": "cron", "expr": "0 9 * * 1", "tz": "Asia/Shanghai" },
  "payload": { "kind": "agentTurn", "message": "执行上下文检查；若无差异请回复 NO_REPLY（静默）" },
  "sessionTarget": "isolated",
  "delivery": { "mode": "announce" }
}
```

### 2. 事件触发（检测到新增模型时主动提示）

当你往配置里新增了模型，技能可以主动问一句"要不要顺便把窗口配上"。
需要额外的变更检测（脚本或 hook），属可选增强，不影响主流程使用。

### 3. 比例可调（默认 60%）

默认按厂商标称窗口的 60% 配置。如果你希望更激进（吃更多窗口）或更保守，可在对话里直接说明要求，例如：
> 「上下文检查，比例用 50%」／「这个模型按 80% 配」

技能会让每个模型单独设置，比例不写死。

## 安全与回退

- 改动前保留一份**改前配置快照**，支持一条指令回退：「撤销上次上下文调整」
- 只在你确认后才写配置；**不存在静默改配置的路径**
- **不记录修改历史、不生成审计文件**：技能只做当下这次检测与执行，用完即走

## 常见问题

**Q：检测要多久？**
约 30–60 秒（主要花在去各家官网取数）。

**Q：官网取不到怎么办？**
技能会请你给一个官方链接，或选择"按现状跳过"，绝不静默沿用旧值。

**Q：会不会改到我其它设置？**
不会。只写模型的窗口字段，其它参数一律不动。

**Q：为什么是 60%？**
留余量给提示词、工具输出与多轮对话，避免模型在长上下文里注意力分散。

## 附：为什么"检查一下"就够了

技能内部固化了这条判断：**窗口按厂商标称的 60% 设置，压缩交给系统默认**。
所以你不需要记任何参数 —— 说一句「上下文检查」，看一张卡，回一个数字。
